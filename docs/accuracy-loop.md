# 用真實樣本與回饋提升精準度

這份說明怎麼把大量照片、截圖、檔案和你的回饋，變成可量測、可回歸、可自動調整的精準度。
目前的「訓練」分三層，由便宜到昂貴：

| 層 | 做什麼 | 需要什麼 | 現在可用 |
|---|---|---|---|
| 1. 評測 | 每一批樣本都打分數，和上一版比，看哪裡進步、哪裡退步 | 樣本檔案；標準答案可有可無 | 可用 |
| 2. 調參與校準 | 自動調整門檻與容差；把「信心值 0.9」校準成「真的九成是對的」 | 樣本加回饋或標準答案 | 可用 |
| 3. 訓練模型 | 用累積的標註資料微調文字辨識、字型分類、版面模型 | 數千筆以上的標註資料，以及 GPU | 資料格式已備好，訓練流程尚未建 |

## 一、放樣本

```
樣本目錄/
  posters/                 ← 子目錄就是分組，報表會依分組列出
    展覽海報.jpg
    展覽海報.truth.json    ← 可選：標準答案
    展覽海報.feedback.json ← 可選：回饋
  slides/
    季報.pdf
  screenshots/
    網頁截圖.png
```

- 一個檔案就是一個樣本：PDF、PNG、JPEG。
- 標準答案與回饋檔要和樣本同名（例如 `季報.truth.json`）。
- 原生 PDF 不需要標準答案：系統會把它畫成截圖、掃描、照片三種干擾版本，用 PDF 本身的內容當答案（自我監督）。這是最便宜的大量評測來源。

## 二、跑評測

```bash
python -m mortise.eval run 樣本目錄 --out 報表目錄
```

和上一次比較：

```bash
python -m mortise.eval run 樣本目錄 --out 報表目錄 --baseline 上一次的報表目錄/summary.json
```

打開 `報表目錄/summary.md`：每個指標的平均、依輸入類型與分組拆開、最差的十個樣本，以及和基準相比的進步與退步（退步會用粗體標出）。

第一個基準在 `tests/eval/baseline_summary_20261121.json`。

## 三、標準答案（照片與截圖才需要）

先讓系統產生草稿，再修改：

```bash
python -m mortise.eval truth-template 樣本目錄/posters/展覽海報.jpg
```

草稿是目前辨識的結果；改正錯的地方（文字、字級、字型、顏色、哪些行屬於同一段）後存成 `.truth.json`。

## 四、回饋

兩個來源，格式相同（`mortise.feedback/1`）：

1. 網頁介面：使用者在修正畫面改字型、字級、文字、角色，或給整頁評分、標示某個元素對或錯。
   - 只有上傳時勾選「同意用於改善辨識」的檔案，才會連同修正與評分收進回饋資料庫（`MORTISE_FEEDBACK` 目錄，預設 `jobs/_feedback/samples/`）。
   - 每一筆修正都會記下系統當時的值與信心值，之後才能做校準。
   - 回饋資料庫本身就是一個樣本目錄，可以直接拿去跑評測。
2. 手寫 `.feedback.json`：格式說明在 `mortise/eval/feedback.py` 開頭。

## 五、校準與調參

把回饋轉成標註資料：

```bash
python -m mortise.eval annotations --store 回饋目錄 --out 標註.jsonl
```

建信心值校準表（樣本不足時會說明不足，不會硬算）：

```bash
python -m mortise.eval calibrate 標註.jsonl
```

自動調參：在 `mortise/config/tunable.toml` 列出的範圍內，一次調一個參數，找出讓總分最高的設定；預設保留四分之一樣本當驗證，避免只對這批樣本有效：

```bash
python -m mortise.eval tune 樣本目錄 --out 調參目錄 --variants screenshot,photo
```

產生的 `調參目錄/override.toml` 可以這樣套用：

```bash
python -m mortise.eval run 樣本目錄 --config 調參目錄/override.toml
```

確認進步後，把數值抄進 `mortise/config/default.toml`。

## 六、建議的節奏

| 階段 | 樣本量 | 做什麼 |
|---|---|---|
| 第一週 | 每類 20 份（海報、簡報、文件、表格、截圖） | 跑評測，看最差的十個樣本，回報具體問題 |
| 第一個月 | 每類 100 份，其中 20 份有標準答案 | 每次改版前後都跑評測；開始調參 |
| 之後 | 回饋資料庫累積到數千筆修正 | 校準信心值；評估微調文字辨識與字型分類模型 |

## 七、要注意的事

- 使用者的檔案沒有同意就不會進入評測或訓練資料，30 天後自動刪除。
- 用來訓練模型的資料，授權要清楚：自己拍的、取得同意的、或可商用的資料集。
- 合成的照片目前沒有模擬鏡頭桶形變形、紙張彎曲、摩爾紋、反光；真實照片的分數會比合成的低，這正是需要真實樣本的原因。
