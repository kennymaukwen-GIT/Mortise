# Mortise 架構總覽

這份是整個系統的地圖：七個階段、每個階段的每個步驟、由什麼工具負責、AI 在哪裡介入、程式在哪裡、目前做到哪裡。
細節設計在同目錄的各階段文件；查證過的授權與套件現況在 `research/`。

狀態欄：**完成** 已實作並有測試；**部分** 已實作但有已知缺口；**規劃** 尚未實作。

## 一、總原則

| 項目 | 內容 |
|---|---|
| 流水線 | 檔案 → ①輸入 → ②頁面 → ③辨識 → ④結構 → ⑤設定 → ⑥輸出 → ⑦驗證 → 下載 |
| 規則一 | 每個階段只交出自己的產物，交出後不可改 |
| 規則二 | 可以讀任何上游產物，不能往回寫 |
| 規則三 | 回頭修改只有「修正單」一種形式（來源：驗證、AI、使用者）；使用者的修正信心值 1.0，之後任何重跑都不覆蓋 |
| 規則四 | AI 只回答編號、標籤、或在候選中選擇；座標與數值一律由演算法量測 |
| 分工 | 量測歸演算法、感知歸小模型、理解歸大型 AI、驗證歸渲染；生成（底圖修補）是明列的例外，報告中標示 |
| 座標 | 頁寬為 1 的相對座標；實際尺寸只存在 PageSpec 的比例尺，改尺寸不必重跑辨識 |
| 快取 | 每個階段的快取鍵＝階段版本＋相關設定＋上游產物＋送給該階段的修正單；升級一個步驟只從那裡重跑 |

## 二、產物（`mortise/artifacts/`）

| 產物 | 誰交出 | 內容 |
|---|---|---|
| 來源文件 SourceDoc | ① | 頁面清單、每頁輸入類型與信心值、假原生初判、中繼資料、使用者意圖 |
| 頁面規格 PageSpec | ② | 頁面四角、長寬比、來源到頁面的矩陣、工作影像、未增強影像、比例尺（含來源與信心值）、尺寸候選 |
| 元素清單 ElementList | ③ | 文字行（四角、內容、候選字、字級原始量測與誤差、字型候選、粗斜體、顏色、基線、逐字位置）、圖片、形狀（含圓角、自訂路徑）、表格區與格線、底圖（含生成區域） |
| 版面 Layout | ④ | 段落、文字框、角色、對齊、閱讀順序、圖層、組裝編號（文字流、包含、同樣式）、表格結構、對齊線、母片候選 |
| 成品文件 StyledDoc | ⑤ | 吸附後的設定值（pt）、字型定案（推論字型與驗證字型分開）、段落屬性、樣式表、主題色、表格（欄寬、列高、邊距、框線、底色、數字格式） |
| 檔案 OutputFile | ⑥ | 各格式的檔案、降級紀錄、寫入的字型、自檢結果 |
| 還原度報告 FidelityReport | ⑦ | 每個元素每個欄位的來源狀態、整頁相似度、文字與斷行一致性、位置誤差、問題清單、提出的修正單 |
| 修正單 Correction | ⑦、AI、使用者 | 目標階段與步驟、元素、欄位、新值、來源、輪次 |

## 五、AI 使用點

| 階段 | 使用點 | 給 AI 什麼 | AI 只能回什麼 | 驗證方式 | 狀態 |
|---|---|---|---|---|---|
| ③ | 候選字仲裁 | 不確定的幾行疊成的影像、辨識結果與候選字 | 每個位置的候選序號 | 序號在候選範圍內、每個位置恰好一次 | 完成 |
| ④ | 角色與閱讀順序 | 段落、圖片、表格編號標記的頁面影像與段落開頭 | 每段的角色、所有編號的順序 | 編號存在且不重複不遺漏、角色在清單內 | 完成 |
| ② | 找不到頁面邊緣 | 縮圖 | 大概區域的格子編號 | — | 規劃 |
| ③ | 區域分類仲裁 | 區域編號標記圖 | 每區的類型 | — | 規劃 |
| ④ | 無框線表格欄位歸屬 | 文字行編號標記圖 | 每行的列與欄 | — | 規劃 |
| ⑤ | 樣式命名 | 樣式清單與範例 | 名稱（不改值） | — | 規劃 |
| ⑦ | 差異歸因 | 原圖與渲染的差異區 | 原因清單中的一項 | — | 規劃 |

不合法的回答會帶著錯誤說明重問一次；仍不合法就放棄，沿用規則的結果。沒有憑證時全部走規則。
